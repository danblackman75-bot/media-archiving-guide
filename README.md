# Family Media Archiving Guide

A static, mobile-friendly guide to digitizing family photos, home videos and discs: what to buy, how to do it, and how to back it up. Prices checked October 25, 2026.

Single `index.html` with inline CSS and JS. Charts use Chart.js from the jsDelivr CDN. Product photos in `assets/img/` come from each manufacturer's or retailer's product page and belong to their owners.
